# Release checklist 1.0.0

## Автоматические проверки

- [ ] Чистая установка по `pnpm-lock.yaml` с `--frozen-lockfile --ignore-scripts`.
- [ ] `pnpm release:check` завершён без предупреждений и ошибок.
- [ ] Production-сервер стартует из `dist`.
- [ ] `/` отвечает 200, содержит корректные title/description/Open Graph.
- [ ] На production-домене присутствует enforced CSP и остальные security headers.

## Smoke-сценарии

- [ ] Главное меню: новая игра; при существующем сохранении показано подтверждение.
- [ ] Продолжение восстанавливает координаты, инвентарь, главу и мир.
- [ ] Клавиатура: движение, добыча, установка, взаимодействие, выбор слота, пауза.
- [ ] Мышь: левое и правое действие; context menu не появляется на Canvas.
- [ ] Touch layout: крестовина, три действия, toolbar; интерфейс не перекрывает цель.
- [ ] Глава 0: радио → 3 дерева/3 камня → кирка.
- [ ] Глава 1: 2 кристалла → резонатор → радио.
- [ ] Глава 2: Хранитель Ноль.
- [ ] Глава 3: три тени → Печать → Шов.
- [ ] Глава 4: три уникальных ядра.
- [ ] Глава 5: Сердце; каждый выбор показывает свой эпилог.
- [ ] После эпилога включается свободный режим.
- [ ] При потере здоровья восстановление у капсулы сохраняет прогресс.
- [ ] Повреждённое сохранение отклоняется и не ломает меню.

## Visual и accessibility

- [ ] 1440×900, 1024×768, 390×844 и landscape mobile.
- [ ] Нет горизонтального скролла, обрезанных модалей и недоступных кнопок.
- [ ] Навигация Tab/Shift+Tab и видимый focus.
- [ ] `prefers-reduced-motion` отключает непрерывную анимацию.
- [ ] Canvas имеет текстовую accessible name, события объявляются live-region.
- [ ] Social card 1200×630, favicon и apple touch icon открываются.

## Handoff

- [ ] `CHANGELOG.md` соответствует версии.
- [ ] Runbook и rollback проверены.
- [ ] Deployment URL записан в релизе.
- [ ] Известные ограничения и решение о телеметрии задокументированы.
