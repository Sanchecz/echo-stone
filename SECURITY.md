# Security policy

## Поддерживаемая версия

| Версия | Поддержка |
| --- | --- |
| 1.0.x | Да |
| < 1.0 | Нет |

## Сообщение об уязвимости

Не публикуйте рабочий exploit в открытом issue. Передайте владельцу проекта описание, минимальное воспроизведение, затронутую версию и ожидаемое влияние через приватный канал площадки, на которой размещён репозиторий.

Целевое подтверждение получения — 3 рабочих дня, первичная классификация — 7 рабочих дней. Срок исправления зависит от влияния. До выпуска исправления просим не раскрывать детали публично.

## Модель угроз

- Сохранение и его JSON считаются недоверенными, даже если пришли из localStorage.
- Внешний HTML, скрипты, iframe, аналитика и сетевые игровые API отсутствуют.
- Worker ограничивает источники контента и запрещает embedding приложения.
- Секреты не нужны для runtime и не должны попадать в клиентский bundle или `.env` в репозитории.
- Dependency updates принимаются только после полного `release:check` и просмотра lockfile.
