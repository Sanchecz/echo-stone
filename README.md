# Эхо Камня

«Эхо Камня» — законченная русскоязычная voxel-adventure для браузера. Игрок исследует процедурный изометрический мир, разбирает и устанавливает блоки, собирает инструменты, сражается с тенями и проходит шесть сюжетных глав до одного из двух эпилогов. После финала мир остаётся доступным в свободном режиме.

Проект не использует чужие игровые ассеты, брендинг или код. Визуальный мир рисуется собственным Canvas-рендерером, а состояние хранится локально в браузере.

## Игровой цикл

1. Найти полевое радио и получить последнюю запись экспедиции.
2. Добыть дерево и камень, собрать кирку.
3. Найти кристаллы, собрать резонатор и открыть голос планеты.
4. Встретить Хранителя Ноль, победить три тени и закрыть Шов бури.
5. Вернуть ядра Рощи, Высоты и Глубины.
6. Дойти до Сердца Эха и выбрать: соединить его с людьми или освободить.

Оба решения имеют завершённый эпилог. Сохранение происходит автоматически после изменения состояния. «Новая история» просит подтверждение, прежде чем заменить существующий мир.

## Управление

| Действие | Клавиатура и мышь | Сенсорный экран |
| --- | --- | --- |
| Движение | `WASD` или стрелки | Крестовина |
| Добыть / атаковать | `Space`, `Q` или левая кнопка | «Добыть» |
| Поставить блок | `F` или правая кнопка | «Ставить» |
| Взаимодействовать | `E` | «Связь» |
| Выбрать блок | `1`—`4` | Ячейка инвентаря |
| Верстак / архив | `C` / `M` | Кнопки панели |
| Пауза | `Esc` | «Пауза» |

Клик по миру одновременно выбирает направление действия. На интерфейсе всегда видны текущая сюжетная цель, здоровье, координаты, ресурсы и уведомление о результате последнего действия.

## Стек и архитектура

- Next.js 16 + React 19 + TypeScript со строгой проверкой типов.
- vinext/Vite для сборки React Server Components в Cloudflare Worker-совместимый ESM.
- Canvas 2D для изометрического рендера без тяжёлого WebGL-фреймворка.
- Чистое доменное ядро в `lib/game-core.ts`: генерация мира, действия, крафт, бой, сюжет и валидация сохранений.
- Отдельный рендерер `lib/render-world.ts`, не меняющий игровое состояние.
- Клиентская оболочка `app/GameClient.tsx`: ввод, звук, HUD, модальные сцены и автосохранение.
- Worker `worker/index.ts`: запуск приложения, оптимизация изображений и защитные HTTP-заголовки.

Подробности находятся в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), а эксплуатация — в [`docs/RUNBOOK.md`](docs/RUNBOOK.md).

## Требования

- Node.js `>=22.13.0` (версия закреплена в `.node-version`).
- pnpm `11.19.0` (версия закреплена полем `packageManager`).

## Локальный запуск

```bash
pnpm install --frozen-lockfile
pnpm dev
```

После запуска приложение доступно по адресу, который напечатает vinext (обычно `http://localhost:3000`).

Production-сборка и локальный production-сервер:

```bash
pnpm build
pnpm start
```

## Проверки

```bash
pnpm typecheck       # строгая проверка TypeScript
pnpm lint            # ESLint, предупреждения считаются ошибками
pnpm test:unit       # генерация мира, ресурсы, крафт, весь сюжет, сохранения
pnpm test            # unit + production build + SSR/security integration
pnpm release:check   # чистое состояние и полный релизный цикл
```

`release:check` удаляет только генерируемые каталоги текущего проекта (`dist`, `.next`, `.wrangler`) и затем заново выполняет все обязательные проверки.

## Сохранения и приватность

Сохранение хранится только в `localStorage` устройства по ключу `echo-stone-save-v1`. На сервер не отправляются прогресс, ввод, идентификаторы или аналитика. При загрузке все поля проверяются: версия, размеры мира, диапазоны координат, допустимые блоки, инвентарь, главы, противники и длина текстовых полей. Повреждённое или подменённое сохранение не используется.

## Поддержка браузеров и доступность

Целевая матрица: актуальные стабильные версии Chrome, Edge, Firefox и Safari, включая iOS Safari и Chrome Android. Нужны Canvas 2D, `structuredClone`, `ResizeObserver`, ES2022 и `localStorage`.

- Полностью доступное управление без мыши.
- Семантические кнопки, подписи Canvas и объявления игровых событий через live-region.
- Видимый focus state и ссылка пропуска к управлению.
- Адаптивная сенсорная раскладка.
- Отключение непрерывной анимации через `prefers-reduced-motion`.
- Поддержка forced-colors и контрастная текстовая оболочка поверх Canvas.
