# Архитектура «Эха Камня»

## Границы системы

Приложение намеренно остаётся однопользовательским и device-local. Сервер отдаёт код и ассеты, но не получает игровое состояние. Это исключает учётные записи, персональные данные, конфликт синхронизации и доступ к чужим мирам. D1 и R2 в `.openai/hosting.json` отключены.

```text
Клавиатура / мышь / touch
            │
            ▼
     React GameClient ───── localStorage (валидированное сохранение v1)
            │
            ├── чистые команды ──▶ game-core.ts ──▶ новое GameState
            │
            └── кадр ────────────▶ render-world.ts ──▶ Canvas 2D

HTTP request ──▶ Cloudflare Worker ──▶ vinext RSC handler ──▶ SSR shell/assets
                       └─────────────▶ security headers
```

## Состояние игры

`GameState` содержит только сериализуемые данные:

- seed и массив ячеек 22×22 со слоями блоков;
- координаты, направление и здоровье игрока;
- инвентарь и собранные инструменты;
- глава, шаг, возвращённые ядра, диалог и финальный выбор;
- противников, ход, день, выбранный блок и короткое уведомление.

Команды (`movePlayer`, `primaryAction`, `placeBlock`, `interact`, `craftItem`) принимают состояние и возвращают новое. Рендерер не имеет права менять состояние. Это делает правила воспроизводимыми и позволяет тестировать полный сюжет без браузера.

## Генерация и рендер

Генератор использует детерминированный PRNG Mulberry32, рельеф из гармоник и фиксированные сюжетные точки. Одинаковый seed всегда создаёт одинаковый мир. Вокруг сюжетных узлов поверхность выравнивается, затем размещаются деревья, кристаллы и неразрушаемые древние блоки.

Canvas использует изометрическую проекцию и рисует блоки от дальних к ближним. Камера следует за игроком; объекты за пределами viewport отбрасываются до отрисовки. Pixel ratio ограничен значением 2 для предсказуемой нагрузки на мобильных устройствах. При `prefers-reduced-motion` постоянный animation frame отключается и кадр обновляется только при состоянии или resize.

## Сюжетная машина

Шесть глав образуют конечный автомат. Переход требует проверяемого действия: взаимодействия с конкретным узлом, рецепта, победы над противниками или сбора уникальных ядер. Финальный выбор доступен только после трёх ядер. Оба эпилога переводят игру в отмеченное завершённое состояние, после чего игрок может перейти в свободный режим.

## Сохранение

Запись выполняется с небольшим debounce после каждого изменения `GameState`. `restoreGame` не доверяет JSON: проверяет глубину и размеры мира, допустимые enum, целые числа и диапазоны, уникальность ядер, известные диалоги, число противников и лимит пользовательски изменяемых строк. Миграция будущих форматов должна добавляться отдельной функцией; значение `SAVE_VERSION` менять без миграции нельзя.

## Web-контур

vinext формирует Cloudflare Worker-совместимый ESM. Worker оборачивает и обычные ответы, и endpoint оптимизации изображений защитными заголовками: CSP, запрет framing, `nosniff`, COOP, CORP, Referrer Policy и Permissions Policy. На localhost CSP работает в Report-Only, чтобы не ломать HMR; на опубликованном домене тот же policy применяется принудительно.

Стиль `unsafe-inline` оставлен только для CSS и RSC bootstrap script, которые генерирует текущий runtime. Пользовательский HTML не формируется, `dangerouslySetInnerHTML` не используется, внешние скрипты и сетевые API отсутствуют.
